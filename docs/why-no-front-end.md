# Why no front end

An HR operator asks for unfinished proposals, budget exceptions or agreement evidence. The agent runs the CLI and returns the records. Read-only HTML snapshots and decision packs use the business identity in brand.json. They have no action buttons.

A screen offers manager self-service, mobile access, drag-and-drop and a visual workbook. This base has one trusted operator, no employee portal and no offline synchronisation. Generated files are snapshots, not live shared records. Database storage on disk is not an encrypted HR vault. Build authenticated identity, permissions, backups and secure file distribution before team use.

The database contains actual annual salaries and proposals, not tax, pension, hourly award rules or market data. Those remain with the employer's systems and advisers. A different stack or team screens can be scoped into the version Enterprise DNA builds and runs.
